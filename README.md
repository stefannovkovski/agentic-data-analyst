# Agentic Data Analyst

**Агентски систем за автономна анализа и адаптивна визуелизација на податоци**

An AI agent system that connects to your data, works out what it is about, and designs a
dashboard for that specific data. You can ask it questions in plain language, and it
watches the data and alerts you about important changes.

> Bachelor's thesis project. Work in progress.

## Project structure

```
backend/        Python API and AI agents
frontend/       React web app
sample-data/    sample database for development and testing
docs/           notes, diagrams and evaluation results
```
